# Abhishek Shaju — Python Developer Portfolio

A responsive dark-theme static portfolio site.

## Files
- `index.html` — portfolio sections and page structure
- `style.css` — responsive dark theme, visual effects, and human AI portrait styling
- `script.js` — navigation, scroll reveals, guide messages, animated counters, cursor-tracked character pupils, and blinking
- `assets/ai-human-hero.webp` — AI-generated human character portrait used in the hero and portfolio guide
- `resume.pdf` — attached resume PDF

## Run locally
Open `index.html` in a browser. For best behavior, serve this folder with a static development server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
This is a static site with no build step. It can be hosted through Vercel, Netlify, or GitHub Pages.
