# Abhishek Shaju — Python Developer Portfolio

A responsive dark-theme static portfolio site.

## Files
- `index.html` — portfolio sections and page structure
- `style.css` — responsive dark theme, visual effects, portrait eye overlays
- `script.js` — navigation, scroll reveals, guide messages, counters, blinking, and cursor-tracked pupils
- `assets/abhishek-avatar.jpg` — portfolio portrait
- `resume.pdf` — attached resume

## Run locally
Open `index.html` in a browser. For best behavior, serve the folder with a static development server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
This is a static site with no build step. It can be hosted through Vercel, Netlify, or GitHub Pages.
