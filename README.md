# Abhishek Shaju — Python Developer Portfolio

A responsive dark-theme static portfolio site.

## Files
- `index.html` — portfolio sections and page structure
- `style.css` — responsive dark theme, visual effects, and animations
- `script.js` — responsive navigation, scroll reveals, active-section navigation, and animated counters
- `resume.pdf` — downloadable résumé

## Run locally
Open `index.html` in a browser. For best behavior, serve this folder with a static development server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy
This is a static site with no build step. The existing Vercel Git integration can deploy updates pushed to the connected branch automatically.
